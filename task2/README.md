# Лабораторная работа №2 — Адаптивная вёрстка. Лендинг по макету

Одностраничный лендинг, свёрстанный по макету Figma (Mobile First). Крупная сетка страницы
построена на CSS Grid (`grid-template-columns`, `grid-template-rows`, `gap`, `grid-column/row`),
раскладка внутри компонентов (карточки, меню, кнопки) — на Flexbox. Три контрольные точки:
мобильный (до 767px, базовые стили), планшет (`@media (min-width: 768px)`),
десктоп (`@media (min-width: 1200px)`); медиазапросы только «от мобильного к десктопу».
На мобильной ширине меню визуально превращается в «гамбургер» (CSS/SVG, без JS-логики).
Есть форма обратной связи (Имя / Email / Сообщение / Отправить) со стилями для
обычного состояния, `:hover` и `:focus`, а также плавные переходы (`transition`) на кнопках
и карточках. Отправка формы не реализуется (нет `action` и JS).
