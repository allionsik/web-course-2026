# Лабораторная работа №1 — Семантическая вёрстка. Страница-резюме.

Одностраничное резюме на семантических тегах HTML5. Раскладка выполнена только на Flexbox
(без float и position: absolute/fixed), продемонстрированы justify-content, align-items,
flex-direction, flex-wrap, gap. Глобально задан `box-sizing: border-box`, стили вынесены
во внешний `style.css`, инлайн-стилей нет, JavaScript не используется.

**Как запустить:** открыть `index.html` в браузере или перейти по ссылке GitHub Pages:
`https://<username>.github.io/web-course-2026/task1/`.
