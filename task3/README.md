# Лабораторная работа №3 — Основы JS и DOM: Todo-list.

Интерактивный список задач на чистом JavaScript. Задачи хранятся в массиве объектов
(`{ id, text, completed }`) и рендерятся из него функцией `render()`; разметка каждой задачи
генерируется в JS, в HTML нет `onclick`-атрибутов — все события через `addEventListener`.
Реализовано: добавление задачи (кнопкой и по Enter, с проверкой на пустой ввод),
отметка «Выполнено» (визуально через класс `.completed`), удаление, счётчики
«Осталось: N, Выполнено: M» и фильтр «Все / Активные / Завершённые» (скрытие через
`display: none`, без удаления из данных). Используются `map`/`filter`/`forEach`,
уникальный `id` для каждой задачи, данных между перезагрузками не сохраняется
(localStorage — в лабе №9). Ошибок в консоли нет.
